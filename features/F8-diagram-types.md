# F8: Diagram types

```
F8: Diagram types
├── F8.1: Sequence diagrams — messages in time order
├── F8.2: Gantt charts — tasks over time
├── F8.3: Mind maps — ideas around one topic
├── F8.4: Pyramids — layers of a whole
├── F8.5: Overlapping sets — what two sets share
└── F8.6: Entity-relationship and class diagrams — tables and classes
```

Diagrams that do not fit layers. Each is a type that sets a diagram's space and the operations that apply ([049. An optional type sets the diagram's space](../specs/decisions/049-an-optional-type-sets-the-diagram-s-space.md)).

## F8.1: Sequence diagrams

Messages between parties in time order.

- **Design:** [2. Places are facts, never coordinates](../DESIGNS.md#2-places-are-facts-never-coordinates)

**Stories:**

- An agent draws a sequence diagram, to show who calls whom and when.

## F8.2: Gantt charts

Tasks laid out over time.

- **Design:** [2. Places are facts, never coordinates](../DESIGNS.md#2-places-are-facts-never-coordinates)

**Stories:**

- An agent draws a Gantt chart, to show a plan over time.

## F8.3: Mind maps

Ideas that branch from one topic.

- **Design:** [2. Places are facts, never coordinates](../DESIGNS.md#2-places-are-facts-never-coordinates)

**Stories:**

- An agent draws a mind map, to show ideas around one topic.

## F8.4: Pyramids

Layers stacked as a pyramid.

- **Design:** [2. Places are facts, never coordinates](../DESIGNS.md#2-places-are-facts-never-coordinates)

**Stories:**

- An agent draws a pyramid, to show what rests on what.

## F8.5: Overlapping sets

Sets drawn overlapping, to show what they share.

- **Design:** [2. Places are facts, never coordinates](../DESIGNS.md#2-places-are-facts-never-coordinates)

**Stories:**

- An agent draws overlapping sets, to show what two things share.

## F8.6: Entity-relationship and class diagrams

Tables or classes and how they relate. These may be a type or a kind of node.

- **Design:** [2. Places are facts, never coordinates](../DESIGNS.md#2-places-are-facts-never-coordinates)

**Stories:**

- An agent draws tables and their relations, to explain a data model.
