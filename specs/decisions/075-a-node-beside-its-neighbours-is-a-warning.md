# 075. A node beside its neighbours is a warning

Decided: 2026-11-06

## The problem

A node placed by steps beside every node it connects to failed the write, and the same node placed in a layer did not. The rule rested on the file not telling a slot the agent stated from one the engine chose, and the agent now states every order.

## The choice

A node beside every node it connects to is a warning however it was placed. It only costs longer edges, and a reader still reads everything.

## Not chosen

- Refusing it in a layer too.
  - Some structures want the node there, and nothing in the picture is hidden.
- Leaving the two cases different.
  - The difference had lost its reason.

## Consequences

The agent is told on every write and decides. A node the owner once wanted punished is now drawn, with a warning.
