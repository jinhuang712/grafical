# 075. A box beside its neighbours is a warning

Decided: 2026-11-06

## The problem

A box placed by steps beside every box it connects to failed the write, and the same box placed in a row did not. The rule rested on the file not telling a slot the agent stated from one the engine chose, and the agent now states every order.

## The choice

A box beside every box it connects to is a warning however it was placed. It only costs longer lines, and a reader still reads everything.

## Not chosen

- Refusing it in a row too.
  - Some structures want the box there, and nothing in the picture is hidden.
- Leaving the two cases different.
  - The difference had lost its reason.

## Consequences

The agent is told on every write and decides. A box the owner once wanted punished is now drawn, with a warning.
